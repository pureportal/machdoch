# Media Studio refinement — 2026-09-14

This iteration builds on [the connected-workflow report](media-studio-workflows-2026-09-14.md). It adds visual assessment, adjustable masks, and refinement from a previous result, then rechecks connected execution against the desktop backend. Earlier successes are not counted as verification of this iteration.

## Changes

- **Check image** uses local Qwen3-VL to assess one to eight visual criteria, optionally against a reference image. Reports retain criteria, verdicts, evidence, raw responses, model information, and image identities. Gates combine visual results with technical measurements; the inspector shows decisions from every attempt. **Measure image** identifies the existing technical-only analyzer more clearly.
- The vision model has a pinned, hash-verified download through the existing installer. Model selection is in Basic settings; image detail and token limits remain in Expert settings. The managed runtime needs no new Python dependency.
- **Prepare mask** accepts a painted selection or a connected mask and exposes grow/shrink and feather controls. It passes the original image and a source-bound mask to **Edit image**. SAM3 also supports shrinking a selection. Empty masks and mismatched source images fail explicitly. Fixed sibling-module loading in the isolated Python worker.
- Refinement can use the **previous edit** as its next input. The original remains available for reference checks, masks retain their original authority, and attempts record actual source images and seeds. This mode requires an Edit image start step and matching dimensions.
- **Inconclusive → Stop** ends immediately, even when failed checks would repeat. Continue records an explicit inconclusive decision without claiming a pass. Complete JSON responses, including one complete JSON code block, are accepted; invalid or incomplete responses become unknown. Missing criteria are never repaired into a passing assessment.
- **Refine a selected edit** provides a connected template for selection, editing, reference assessment, gating, bounded refinement, and saving.
- Fixed toolbar clipping, prompt instructions being shortened on save, and queued workflows losing executor information, output counts, and evidence. Intermediate assets remain distinct from final outputs. Progress follows the current step. Run and its keyboard commands wait while a saved workflow loads. Opening or inspecting a workflow no longer leaves a misleading notice naming a different flow.

## Defects fixed and model limitations

The isolated worker's missing sibling import and rejection of a complete JSON code block were implementation defects, both fixed and regression-tested. Full-strength blue and garden trials encountered the parser defect before downstream saving. The final blue chain and garden assessment/save runs above used the corrected parser.

The vision model is **uncalibrated**. An initial trial (`workflow-run:d6bc5345-b010-4e3b-9ddb-84ea39e8f674`) described two mug handles yet passed the exactly-one-handle criterion. Evidence-first instructions improved the subsequent mug result, but the final halo assessment still contradicted itself. Several assessments also misstated the reference image's color or background. These are model errors; structurally valid JSON cannot establish correct visual reasoning. Pixel comparisons independently establish the tested protected-pixel preservation.

In `workflow-run:bb301945-c4f8-4b13-bd68-7a216ad0204c`, the model classified an unseen mug serial number as **fail**, rather than **unknown**. The failure policy consequently retried and exhausted two attempts. This does not verify recognition of missing visual evidence. The explicitly truncated tests separately verify unknown handling.

**SAM3 inference remains blocked.** A fresh request for the official gated weights returned HTTP 401, and no authorized weights are installed. Painted masks, source-identity checks, and mask-processing tests do not verify actual SAM3 detection quality or the complete live SAM3-to-edit path.

Mask growth makes additional boundary pixels editable and can affect adjacent subject pixels. Preservation claims apply outside the effective mask, before upscaling. The blue dress retains a thin red fringe at part of the painted boundary; upscaling preserves it, and the broad blue-dress criterion did not reject it. The garden's gray halo is substantially reduced, but its lighting is not fully integrated. Neither compositing nor an AI pass guarantees natural edges or visual correctness.

This iteration did not verify automatic convergence to an intended edit, automated video-content or motion assessment, other upscaler architectures/scales, other vision models, other hardware, or packaged builds. Existing Basic/setup flows have regression coverage; the new live generation test used a connected Advanced workflow.

Two verification-harness incidents are excluded from product findings: a selection that was not awaited launched the preceding test workflow and was canceled during model loading; a temporary delayed-call wrapper raised a JavaScript error after its reference was removed. Final checks used loaded saved graphs and restored native calls.
