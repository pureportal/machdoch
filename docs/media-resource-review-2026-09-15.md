# Media Studio resource discovery — 15 September 2026

## Changes

Resource search and filtering now use the same metadata in the Assets library, Basics, and Advanced. The implementation reuses the existing category and tag model; it adds no resource schema or migration.

| Gap observed in the running UI and source                                                                                         | Change                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Model pickers ignored organised metadata; the separate Advanced add-on search used category IDs instead of their displayed names. | Shared, case-insensitive search across names, tags, category names, architecture, trigger words, and relevant resource metadata. Multiple search words can match different fields.                                                                                                                    |
| Finding an item depended on scrolling and inconsistent filters.                                                                   | Category, tag, and name sorting in model and add-on pickers; import-date sorting for add-ons. The library also filters models/add-ons by base family and groups its All view by resource kind. Library tag choices are scoped to the resource type and deduplicated without regard to capitalisation. |
| Basics hid add-ons under More options; Advanced had a separate narrow picker under Expert.                                        | A shared **LoRAs and embeddings** dialog in the main creation controls and the Advanced node's Basic tab. Select several items in one opening, adjust their settings, review Selected only, and close with Done. Changes apply immediately.                                                           |
| Image inputs exposed long image grids without adequate discovery controls.                                                        | A shared image browser for base, reference, pose, and Advanced asset inputs, with search, category/tag filters, sorting, Selected only, previews, dimensions, timestamps, and 24 images per page.                                                                                                     |
| Choosing the already-selected model could reset its add-ons.                                                                      | Selecting the current model leaves its settings intact. Switching to a different model still performs the existing compatibility reconciliation.                                                                                                                                                      |
| Refreshing metadata could erase unfinished tag input.                                                                             | Tag drafts reset only when their saved content or resource changes.                                                                                                                                                                                                                                   |
| Narrow add-on cards broke the strength label across several lines.                                                                | The grid keeps enough width for each card's controls and uses one column when needed.                                                                                                                                                                                                                 |

Selections remain keyed by immutable resource IDs. Filtering and sorting change the visible list without rebuilding the selection stack. The existing compatibility checks, capacity limits, strength settings, embedding placement/token, and generation compiler remain in use. Duplicate picker implementations and their obsolete search helper were removed.

## Limits

- Discovery uses recorded metadata. It does not infer style from tensor weights, classify previews, or fetch additional resources.
- The tested two-LoRA combination has poor image quality. Other combinations, base models, and GPUs were not tested by real generation in this review.
- Embedding selection, persistence, conversion, and compilation were checked; embedding rendering was not reverified. The earlier embedding runtime findings are not claimed resolved.
- Image selection was exercised, but this review did not repeat the complete base/reference/mask/transparency generation matrix. Video/SVG generation and video LoRAs were not added or reverified.
- A transient run-not-found banner appeared while an Advanced run waited for native registration behind another job; the run subsequently completed. That queue-status issue was not changed here.
- An intentionally unconnected image source in the review graph blocked saving during test setup. Connecting its output cleared the validation failure and conversion then worked. It did not alter or lose its chosen asset.

The repository already contained other uncommitted Media Studio work. This review preserved it and limited implementation changes to resource discovery and selection.
