## Implementation

Basic training selects an installed base model, method, concept, trigger, and images. Advanced controls expose precision, optimizer, trainable weight precision, batch size, gradient accumulation, learning-rate scheduling and warmup, weight decay, gradient clipping, Min-SNR weighting, noise offset, LoRA dropout and target layers, aspect buckets, gradient checkpointing, and checkpoint retention. Embedding training requires an initializer word and a single token.

One Stable Diffusion runtime handles the four related UNet architectures. A shared flow runtime handles SD3's three text encoders, FLUX.1's packed latents and position IDs, and SANA's deterministic latents and masked Gemma conditioning. FLUX.1 dev exposes training guidance; Schnell passes no guidance embedding. Both runtimes share the optimizer and checkpoint loop, cache latent distributions or deterministic latents with frozen text conditioning, sample fresh training noise, and save optimizer, scheduler, scaler, and random state in atomic checkpoints. Resume checks the dataset, model identity, and settings. Loss, learning rate, elapsed time, and estimated remaining time are recorded per optimizer step.

Model loading, image preparation, checkpoint saving, and weight export appear as current job status. Embedding loading registers and copies the supplied vectors without computing vocabulary-wide initialization statistics; profiling the preceding implementation identified that calculation as an avoidable delay. Existing vocabulary rows and case-sensitive multi-vector aliases are checked separately.

Single-file SD1/SD2 loading retains a safety checker declared in the model configuration. Diffusers otherwise omits this optional component. Missing or unknown declared checkers fail before pipeline loading. SD1 component installation includes the digest-verified checker configuration and safetensors weights, and import storage checks account for those files. Reimport verifies the existing checkpoint and repairs its components directly instead of discarding newly staged components. The 78-check worker suite passed; a focused check also covered unknown checker rejection. All 12 SD1 installation manifest entries matched the independently downloaded, verified component inventory. The native reimport repair check passed.

Finetuning updates every denoiser parameter; the VAE and text encoders remain frozen. It exports a complete safetensors Diffusers package. LoRA exports attention and optional feed-forward adapters. SD3 and FLUX.1 include joint attention and context feed-forward targets; FLUX.1 also includes the single-block feed-forward projections. Textual inversion exports CLIP vectors for SD1/SD2 and SDXL/Pony, CLIP/T5 vectors for FLUX.1 and SD3, or a Gemma vector for SANA. The interface imports each artifact through its model or addon route. Using a trained addon in Basic selects its original installed training base and checks that it remains runnable and compatible. Full FLUX model imports distinguish dev and Schnell using the transformer's guidance configuration.
