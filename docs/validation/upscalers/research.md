## References and implementation

[Spandrel](https://github.com/chaiNNer-org/spandrel) provides architecture detection and model inference under MIT. Its main package includes permissively licensed architectures; individual imported weights still have their own terms. Machdoch does not install `spandrel_extra_arches`.

[ComfyUI's model-upscale node](https://github.com/comfyanonymous/ComfyUI/blob/master/comfy_extras/nodes_upscale_model.py) is a useful workflow reference: separate model selection from the image operation and tile inference to bound GPU memory. No ComfyUI source was copied. Machdoch's implementation uses its existing typed image/video ports, revisioned flows, local queue, cancellation, asset provenance and offline workers.

The image path processes padded tiles at native model scale, crops the padding, then downsamples when 2× is selected for a 4× model. Alpha is resized separately. The video path loads the model once, streams frames through the same image operation, writes VP9 WebM, copies the existing audio, and validates decoded frame count/rate and audio presence. Frame processing keeps one decoded frame and its upscale in memory rather than loading the entire clip; metadata validation still scans the clip. These presets process frames independently; they do not claim temporal restoration or motion compensation.

Inference runs offline. Explicit model installation downloads hash-verified weights and their full license files; no media is uploaded. Download records are in [model-downloads.json](model-downloads.json). Built-in weights are downloaded separately, not bundled with the app. Attribution and full license copies are in [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md) and `legal/third-party/upscalers/`.

## Validation

See [gpu-results.json](gpu-results.json) for real RX 9070 runs. Tests check dimensions, alpha, differences from Lanczos, and every video frame rather than only the first/last frame. Native Playwright results and screenshots are recorded alongside this document. These are functional checks on small fixtures, not a benchmark claiming one model has the best perceptual quality.

Nomos8kDAT is listed under CC BY 4.0 with attribution required. The Civitai listing pages could not be opened in this run; their weight availability and license terms were not independently confirmed here.
