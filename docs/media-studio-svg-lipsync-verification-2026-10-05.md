The revised device map assigns the language model and output head to the selected GPU, allocates remaining memory to vision blocks, and uses the current Transformers offloaded cache. It reports insufficient memory explicitly. This device assignment does not prove physical GPU residency on Windows, whose counters also reported shared GPU memory. See the publisher's [refinement implementation](https://github.com/gitcat-404/IntroSVG/blob/master/inference_loop.py), [renderer API](https://resvg-py.readthedocs.io/en/latest/api.html), and [cache documentation](https://huggingface.co/docs/transformers/main/en/kv_cache).
