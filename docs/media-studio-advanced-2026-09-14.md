# Media Studio advanced workflows — 2026-09-14

This iteration revalidates [the refinement report](media-studio-refinement-2026-09-14.md) against the current implementation and the development desktop backend. It concentrates on dependable gate decisions, mask reuse and boundary repair, and the path from an edited image through upscaling to video.

## Implementation

- **Check image** runs two visual reviews by default, with a range of one to three. Reviews use different inspection instructions and alternate the order of labeled result/reference images. Every criterion requires agreement; disagreement, invalid JSON, duplicate fields, or an incomplete response produces an inconclusive result. Reports retain every response and judgment. The node inspector groups these reviews under the corresponding attempt.
- Connecting an **Edit mask** and its **Reference image** adds an exact protected-pixel check. It compares decoded RGBA values outside the effective mask. Changed protected pixels fail; a mask without protected pixels is inconclusive. Image identity, mask ownership, and dimensions are checked. **Compare reference visually** separately controls whether the vision model receives the reference. Masked refinement templates disable visual comparison while retaining exact preservation; comparison can be enabled for relative appearance criteria.
- **Prepare mask** supports the whole selection, its surroundings, or a boundary band, with a boundary radius, growth/shrinkage, and feathering. **Mask reference** permits reuse of an original selection on an aligned edited image. Painting uses that reference. **Refine edit edges** connects boundary preparation, localized editing, checks, a bounded previous-edit loop, and saving. The background example uses full edit strength and asks for a complete outdoor background and floor with lighting matched to the subject; the dress example retains 0.65 strength.
- Refinement detects previously rejected images from decoded pixels, including repeated images with different file encodings and cycles through earlier candidates. By default, it stops before an inconsistent later assessment can accept an unchanged rejected image. Feedback carries failed desired criteria to the first repeated prompt/image generation step, without copying the model's sometimes contradictory explanations into the generation prompt. Attempt limits and the explicit inconclusive policy remain authoritative.
- Output nodes run after the other steps in an attempt. An independent output branch cannot publish before another quality gate rejects the attempt. Activity shows actual **Published / planned** counts and prioritizes final outputs, then the latest intermediate image/video, for previews.
- The upscaler installer now offers **SPAN** alongside Real-ESRGAN. Its small 4× safetensors checkpoint and license are pinned by byte count and SHA-256. It uses the existing Spandrel inference and tiling path, with selectable output scale.
- Fixed Windows Python input decoding: isolated workers now explicitly use UTF-8. Smart punctuation in a criterion previously arrived as mojibake and failed identity validation. Also changed the relevant SQLite publication, progress, retry, and cancellation transactions to acquire the writer lock before reading. A real overlapping run exposed a deferred-transaction upgrade failure; a regression test and subsequent concurrent runs cover the correction.

## Remaining limits

**SAM3 is still blocked in this environment.** A fresh request through the managed Hugging Face client returned HTTP 401 / `GatedRepoError`; no Hugging Face credential or authorized SAM3 package was found in the checked model/cache locations. Mask processing and painted selections do not verify SAM3 inference or detection quality. The full live SAM3 → edit path remains unverified.

Two reviews of the same uncalibrated vision model are not independent validation. Agreement can still accept defects, and structurally valid reasoning can contradict a verdict or invent a reference. The boundary image's pass is not evidence of satisfactory lighting. Exact protected-pixel checks establish preservation only, before resizing/upscaling; they do not assess editable edges, lighting, anatomy, or semantic success.

Mask-reference reuse assumes the images remain spatially aligned; matching dimensions cannot prove alignment. Boundary edits intentionally expose additional nearby pixels to modification. Repetition detection compares exact decoded pixels, not perceptual similarity or a calibrated quality trend. Reliable automatic acceptance and semantic convergence remain unproven.

Other upscaler architectures, other vision models, other hardware, packaged builds, and automated video-content/motion quality assessment have not been established by these checks. Successful execution and saving do not establish satisfactory output quality.
